How This Analysis Works

This analysis follows the sales-comparison approach used in residential brokerage. Recently sold, similar properties are selected and scored for similarity across {{ weights | length }} weighted factors (location, size, type, recency, and features). Each comparable's sale price is then adjusted for measurable differences from the subject — when a comparable is inferior to the subject the price adjusts upward; when superior it adjusts downward. The adjusted values are reconciled into a value range using the similarity weights shown below. Every adjustment amount comes from the stated assumption set, which the preparing agent can and should tailor; none are market standards. The range is an analytical estimate, not a statistical confidence interval.
